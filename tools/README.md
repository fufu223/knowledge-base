# 🛠️ 文档工具说明

本目录包含知识库相关的工具脚本。

**注意**：这些工具仅供文档维护者使用，框架使用者无需关注。

---

## 📋 工具列表

### 1. preview-nodejs.bat
**用途**：启动本地预览服务器  
**要求**：已安装 Node.js  
**使用**：双击运行，访问 `http://127.0.0.1:8080`

### 2. preview-docsify.bat
**用途**：Docsify 预览指南  
**使用**：查看使用说明

### 3. check-deployment.bat
**用途**：检查部署配置  
**使用**：验证文件完整性

### 4. rename-to-chinese.bat
**用途**：批量重命名为中文  
**使用**：文档维护时使用

### 5. test-links.bat
**用途**：测试文档链接  
**使用**：验证所有链接有效

---

## 💡 框架使用者

如果您只是查看文档，不需要使用这些工具。

**推荐方式**：
1. 直接双击 `../index.html` 用浏览器打开
2. 或联系团队获取在线文档地址
