# Fastsun 平台开发文档

## 📖 文档说明

本文档面向 **使用 Fastsun 框架的开发者**，提供框架功能说明、配置指南和开发示例。

**注意**：本文档不包含框架源码实现细节，如需了解框架内部实现，请参考源代码。

---

## 🚀 快速开始

### 查看文档

**方法 1**：直接打开 `index.html` 文件（最简单）

**方法 2**：使用本地服务器（推荐，支持搜索）
```bash
cd tools
.\preview-nodejs.bat
```
访问：`http://127.0.0.1:8080`

**方法 3**：在线文档  
联系团队获取在线文档地址
