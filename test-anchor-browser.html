🧪 锚点定位功能测试

测试说明

打开知识库页面后，在浏览器控制台（F12）运行以下测试代码：

测试 1: 检查内容区域是否存在

const contentArea = document.querySelector('.markdown-section'); console.log('内容区域:', contentArea); console.log('是否可以滚动:', contentArea.scrollHeight > contentArea.clientHeight);

测试 2: 查找带 ID 的标题

const headings = document.querySelectorAll('.markdown-section h1[id], .markdown-section h2[id], .markdown-section h3[id]'); console.log('找到', headings.length, '个带ID的标题'); headings.forEach((h, i) => { console.log(i + 1, ':', h.id, '-', h.textContent.trim()); });

测试 3: 手动触发锚点滚动

// 找到第一个 H2 标题并滚动到它 const firstH2 = document.querySelector('.markdown-section h2[id]'); if (firstH2) { console.log('准备滚动到:', firstH2.textContent.trim()); const contentArea = document.querySelector('.markdown-section'); const elementRect = firstH2.getBoundingClientRect(); const containerRect = contentArea.getBoundingClientRect(); const scrollTop = contentArea.scrollTop; const offsetTop = elementRect.top - containerRect.top + scrollTop - 100; console.log('滚动位置:', offsetTop); contentArea.scrollTo({ top: offsetTop, behavior: 'smooth' }); } else { console.log('未找到带ID的H2标题'); }

测试 4: 模拟点击侧边栏链接

// 找到侧边栏的第一个二级菜单链接 const sidebarLink = document.querySelector('.sidebar-nav ul li ul li a'); if (sidebarLink) { console.log('侧边栏链接:', sidebarLink.href); console.log('链接文本:', sidebarLink.textContent.trim()); // 模拟点击 sidebarLink.click(); // 延迟检查是否滚动 setTimeout(() => { const contentArea = document.querySelector('.markdown-section'); console.log('当前滚动位置:', contentArea.scrollTop); }, 500); } else { console.log('未找到侧边栏链接'); }

测试 5: 检查 URL 中的锚点

console.log('当前 URL:', window.location.href); console.log('Hash:', window.location.hash); // 解析锚点 const hash = window.location.hash; let anchorId = null; if (hash.includes('?id=')) { anchorId = hash.split('?id=')[1].split('&')[0]; } else if (hash.includes('#') && hash.lastIndexOf('#') > 0) { anchorId = hash.substring(hash.lastIndexOf('#') + 1); } console.log('解析出的锚点ID:', anchorId); if (anchorId) { const element = document.getElementById(anchorId) || document.getElementById(decodeURIComponent(anchorId)); console.log('目标元素:', element); }

快速测试步骤

  1. 打开 http://localhost:3000
  2. 按 F12 打开开发者工具
  3. 切换到 Console 标签
  4. 依次复制上面的测试代码并运行
  5. 观察控制台输出和页面滚动效果
