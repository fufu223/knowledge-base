# 业务流程图

本章通过 Mermaid 流程图展示 Fastsun 框架的核心业务流程，帮助开发者理解系统运行的全貌。

---

## 1. 项目启动流程

服务启动时，框架自动完成以下初始化工作：

```mermaid
%%{init: {'theme': 'base', 'themeVariables': {'fontSize': '14px', 'lineColor': '#94a3b8'}}}%%
flowchart TD
    A[启动 Spring Boot 应用] --> B[加载 Bootstrap 配置]
    B --> C[Nacos 配置中心拉取配置]
    C --> D[注册服务到 Nacos 注册中心]
    D --> E[初始化 DataSource 数据源]
    E --> F{多租户模式?}
    F -->|字段隔离| G[加载默认数据源]
    F -->|数据库隔离| H[动态注册各租户数据源]
    G --> I[初始化 Redis 连接池]
    H --> I
    I --> J[缓存预热: 租户信息 / 字典 / 配置]
    J --> K[加载 Sentinel 限流规则]
    K --> L[初始化 Feign 客户端]
    L --> M[初始化 WebSocket 端点]
    M --> N[服务启动完成 / 健康检查就绪]

    classDef start fill:#1e40af,color:#fff,stroke:#1e3a8a,stroke-width:2px,font-weight:bold
    classDef step fill:#e2e8f0,color:#334155,stroke:#cbd5e1,stroke-width:1px

    class A start
    class B,C,D,E,G,H,I,J,K,L,M step
    class F choice
    class N done
```

## 2. 首次请求全流程

从客户端发起到响应的完整请求链路：

```mermaid
sequenceDiagram
    participant Client as 客户端<br/>Web / H5 / APP
    participant DNS as DNS / CDN
    participant Gateway as API 网关<br/>fastsun-gateway
    participant OAuth as 认证服务<br/>fastsun-oauth
    participant Biz as 业务服务<br/>(微服务)
    participant DB as 数据库 / Redis

    Client->>DNS: 1. 域名解析
    DNS-->>Client: 返回网关 IP
    Client->>Gateway: 2. HTTP 请求

    rect rgb(240, 248, 255)
        Note over Gateway,OAuth: 认证鉴权阶段
        Gateway->>Gateway: 3. 白名单 URL 检查
        alt 白名单请求
            Gateway->>Biz: 直接路由
        else 需认证请求
            Gateway->>OAuth: 4. 校验 Token
            OAuth-->>Gateway: 5. Token 有效 / 用户信息
        end
    end

    rect rgb(255, 243, 224)
        Note over Gateway,Biz: 路由转发阶段
        Gateway->>Gateway: 6. 路由匹配 / 负载均衡
        Gateway->>Biz: 7. 转发请求 + 用户上下文 Header
    end

    rect rgb(232, 245, 233)
        Note over Biz,DB: 业务处理阶段
        Biz->>Biz: 8. 解析用户 Token / 设置本地上下文
        Biz->>Biz: 9. 数据权限过滤
        Biz->>Biz: 10. 多租户字段过滤 (Hibernate Interceptor)
        Biz->>DB: 11. 查询数据库
        DB-->>Biz: 12. 返回数据
        Biz-->>Gateway: 13. 统一响应封装 Response<T>
    end

    Gateway-->>Client: 14. 返回响应结果
```

## 3. WebSocket 连接流程

实时消息推送的连接建立过程：

```mermaid
sequenceDiagram
    participant Client as 前端<br/>SockJS + STOMP
    participant WS as WebSocket 服务<br/>fastsun-message-websocket
    participant Auth as 认证服务
    participant Redis as Redis<br/>会话管理

    Client->>WS: 1. HTTP 握手 / SockJS 协商
    WS->>Auth: 2. 验证连接 Token
    Auth-->>WS: 3. Token 有效
    WS-->>Client: 4. 连接建立成功

    Client->>WS: 5. STOMP 订阅 /topic/notifications
    WS->>Redis: 6. 记录用户订阅关系
    WS-->>Client: 7. 订阅确认

    Client->>WS: 8. STOMP 订阅 /queue/user/{userId}
    WS->>Redis: 9. 记录点对点订阅
    WS-->>Client: 10. 订阅确认

    Note over Client,Redis: 连接保持阶段
    Client->>WS: 11. 心跳 Ping (每 30s)
    WS-->>Client: 12. 心跳 Pong
```

## 5. OAuth2 登录认证流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant Client as 客户端
    participant Gateway as API 网关
    participant OAuth as OAuth2 认证服务器
    participant UCenter as 用户中心

    User->>Client: 1. 输入账号密码
    Client->>Gateway: 2. POST /oauth/token
    Gateway->>OAuth: 3. 转发认证请求
    OAuth->>OAuth: 4. 选择登录策略<br/>(用户名密码 / 微信 / 企业微信)
    OAuth->>UCenter: 5. 查询用户信息
    UCenter-->>OAuth: 6. 返回用户 + 角色 + 权限
    OAuth->>OAuth: 7. 生成 Token (Redis / JWT)
    OAuth-->>Gateway: 8. 返回 AccessToken + RefreshToken
    Gateway-->>Client: 9. 返回 Token
    Client-->>User: 10. 登录成功

    rect rgb(255, 235, 238)
        Note over OAuth: 登录策略控制
        Note over OAuth: 首次登录 → 旧 Token 失效
        Note over OAuth: 末次登录 → 禁止重复登录
    end
```

## 6. 网关鉴权路由流程

```mermaid
%%{init: {'theme': 'base', 'themeVariables': {'fontSize': '14px', 'lineColor': '#94a3b8'}}}%%
flowchart TD
    Req[请求到达 Gateway] --> Whitelist{白名单?}

    Whitelist -->|是| Route[路由到目标服务]

    Whitelist -->|否| CheckToken{Token 验证}
    CheckToken -->|无效/过期| AuthFail[返回 401 未授权]
    CheckToken -->|有效| ExtractUser[提取用户信息]

    ExtractUser --> CheckPerm{权限校验}
    CheckPerm -->|无权限| Deny[返回 403 禁止访问]
    CheckPerm -->|有权限| SetContext[设置用户上下文 Header]
    SetContext --> Route

    Route --> LB[负载均衡]
    LB --> Service[调用业务服务]

    classDef entry fill:#1e40af,color:#fff,stroke:#1e3a8a,stroke-width:2px,font-weight:bold
    classDef choice fill:#f59e0b,color:#fff,stroke:#d97706,stroke-width:2px,font-weight:bold
    classDef step fill:#e2e8f0,color:#334155,stroke:#cbd5e1,stroke-width:1px
    classDef error fill:#dc2626,color:#fff,stroke:#b91c1c,stroke-width:2px,font-weight:bold
    classDef success fill:#0d9488,color:#fff,stroke:#0f766e,stroke-width:2px,font-weight:bold

    class Req entry
    class Whitelist,CheckToken,CheckPerm choice
    class ExtractUser,SetContext,Route,LB step
    class AuthFail,Deny error
    class Service success
```

## 7. 数据权限过滤流程

```mermaid
%%{init: {'theme': 'base', 'themeVariables': {'fontSize': '14px', 'lineColor': '#94a3b8'}}}%%
flowchart TD
    Query[业务查询请求] --> UserCtx[获取当前用户信息]
    UserCtx --> Role[查询用户角色]
    Role --> Scope{获取数据权限范围}

    Scope -->|全部数据| All[不添加过滤条件]
    Scope -->|自定义| Custom[查询自定义权限组织]
    Scope -->|本部门| Dept[只查本部门数据]
    Scope -->|本部门及下级| DeptChild[查部门及子部门]
    Scope -->|仅本人| Self[只查本人数据]

    All --> Exec[执行查询]
    Custom --> AddFilter[添加 tenant_code 字段过滤]
    Dept --> AddFilter
    DeptChild --> AddFilter
    Self --> AddFilter

    AddFilter --> Exec
    Exec --> Result[返回过滤后的数据]

    classDef entry fill:#1e40af,color:#fff,stroke:#1e3a8a,stroke-width:2px,font-weight:bold
    classDef step fill:#e2e8f0,color:#334155,stroke:#cbd5e1,stroke-width:1px
    classDef choice fill:#f59e0b,color:#fff,stroke:#d97706,stroke-width:2px,font-weight:bold
    classDef branch fill:#eff6ff,color:#1e40af,stroke:#bfdbfe,stroke-width:1px
    classDef filter fill:#7c3aed,color:#fff,stroke:#6d28d9,stroke-width:2px,font-weight:bold
    classDef done fill:#0d9488,color:#fff,stroke:#0f766e,stroke-width:2px,font-weight:bold

    class Query entry
    class UserCtx,Role,Exec step
    class Scope choice
    class All,Custom,Dept,DeptChild,Self branch
    class AddFilter filter
    class Result done
```
