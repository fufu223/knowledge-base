# Fastsun 消息通知模块使用教程

## 一、模块概述

### 1.1 功能简介

Fastsun 平台提供了强大的消息通知模块（Reminder），支持多种消息推送方式，包括：

- **站内消息**（Site）：系统内部消息中心
- **企业微信**（WCP）：企业微信应用消息
- **微信公众号**（Wechat）：公众号模板消息
- **手机短信**（Mobile）：阿里云/腾讯云短信
- **电子邮件**（Email）：SMTP 邮件发送
- **极光推送**（JPush）：移动端 Push 通知

### 1.2 模块架构

```
┌─────────────────────────────────────────────┐
│          业务层（你的代码）                    │
│    ReminderComposeService.push(reminderDTO)  │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│         SDK 层（消息组合服务）                 │
│      ReminderComposeService                  │
│  - 微服务模式：调用远程接口                     │
│  - 单体模式：直接调用本地服务                   │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│        Domain 层（核心服务）                   │
│       ReminderServiceImpl                    │
│  - 参数验证                                   │
│  - 租户上下文设置                              │
│  - 消息记录保存                                │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│      Subscribe 层（消息订阅/分发）             │
│   PlatformReminderSubscribe (Redis)          │
│  - 发布到 Redis                               │
│  - 订阅者接收并处理                            │
└──────────────┬──────────────────────────────┘
               │
               ▼
┌─────────────────────────────────────────────┐
│     Processor 层（消息处理器）                 │
│  ┌─────────┬──────────┬──────────┐          │
│  │ Site    │ Wechat   │ Mobile   │          │
│  │ Email   │ JPush    │ WCP      │          │
│  └─────────┴──────────┴──────────┘          │
│  - 根据 templateType 选择对应处理器            │
│  - 调用第三方 API 发送消息                     │
└─────────────────────────────────────────────┘
```

### 1.3 核心组件

| 组件 | 位置 | 作用 |
|------|------|------|
| `ReminderDTO` | `fastsun-base` | 消息数据传输对象 |
| `IReminderComposeService` | `fastsun-reminder-sdk-mix` | 消息推送组合服务接口 |
| `ReminderComposeService` | `fastsun-reminder-sdk-mix` | 消息推送组合服务实现 |
| `IFastsunReminderService` | `fastsun-reminder-api` | 消息服务接口 |
| `ReminderServiceImpl` | `fastsun-reminder-domain` | 消息服务实现 |
| `AbstractMessageReminder` | `fastsun-reminder-processor-base` | 消息处理器抽象基类 |
| `PlatformReminderSubscribe` | `fastsun-reminder-subscribe` | Redis 消息订阅器 |

## 二、快速开始

### 2.1 引入依赖

在你的业务模块 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>com.fastsun.platform</groupId>
    <artifactId>fastsun-reminder-sdk-mix</artifactId>
    <version>${project.version}</version>
</dependency>
```

### 2.2 最简单的使用示例

```java
import com.fastsun.platform.core.dto.ReminderDTO;
import com.fastsun.platform.core.sdk.mix.IReminderComposeService;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

@Service
public class MyBusinessService {
    
    @Autowired
    private IReminderComposeService reminderComposeService;
    
    public void sendNotification() {
        // 1. 创建消息对象
        ReminderDTO reminder = new ReminderDTO();
        
        // 2. 设置必填字段
        reminder.setTemplateType("site");           // 消息类型：站内消息
        reminder.setMessageType("site");            // 消息渠道：站内
        reminder.setDetailType("order_notify");     // 明细类型：订单通知
        reminder.setTemplateId("TPL_ORDER_001");    // 模板ID
        reminder.setReceivers("1001,1002");         // 接收者：用户ID
        
        // 3. 设置消息内容参数
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("orderNo", "ORD20260417001");
        params.put("amount", "999.00");
        reminder.setParams(params);
        
        // 4. 设置标题
        reminder.setTitle("订单支付成功通知");
        
        // 5. 发送消息
        reminderComposeService.push(reminder);
    }
}
```

## 三、核心概念详解

### 3.1 ReminderDTO 字段说明

#### 必填字段

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `templateType` | String | 模板类型（消息大类） | `"site"`, `"wechat"`, `"mobile"` |
| `messageType` | String | 消息类型（发送渠道） | 通常与 templateType 相同 |
| `detailType` | String | 明细类型（业务场景） | `"login"`, `"order_notify"` |
| `templateId` | String | 模板ID | `"TPL_LOGIN_001"` |
| `receivers` | String | 接收者（多个用逗号分隔） | `"1001,1002"` 或手机号 |

#### 常用可选字段

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `title` | String | 消息标题 | `"订单通知"` |
| `params` | Map | 模板参数 | `{"code": "123456"}` |
| `record` | Boolean | 是否记录到数据库 | `true`（默认） |
| `clientShow` | Boolean | 是否在客户端显示 | `true` |
| `link` | String | 点击跳转链接 | `"/order/detail/123"` |
| `extra` | String | 透传参数（JSON） | `"{\"orderId\": 123}"` |
| `tenantCode` | String | 租户编码 | 自动从上下文获取 |

#### 特殊字段（企业微信专用）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `receType` | String | 接收者类型 | `"touser"`, `"toparty"` |
| `wechatType` | String | 微信消息类型 | `"text"`, `"textcard"`, `"image"` |

### 3.2 TemplateType 枚举

```java
public enum TemplateType {
    SITE("site", "站内"),           // 站内消息
    WECHAT("wechat", "微信"),       // 微信公众号
    WCP("wcp", "企业微信"),         // 企业微信
    MOBILE("mobile", "手机短信"),   // 短信
    EMAIL("email", "电子邮件"),     // 邮件
    JPUSH("jpush", "极光推送");     // Push通知
}
```

**数据库表：** `TB_MESSAGE_TEMPLATE`

#### 配置示例

```sql
INSERT INTO TB_MESSAGE_TEMPLATE (
    template_id, 
    template_type, 
    detail_type, 
    title,

    tenant_code
) VALUES (
    'TPL_ORDER_001',
    'site',
    'order_notify',
    '订单{orderNo}支付成功',
    '您的订单{orderNo}已支付成功，金额：{amount}元',
    'default'
);

-- 短信模板（阿里云/腾讯云）
INSERT INTO TB_MESSAGE_TEMPLATE (
    template_id, 
    template_type, 
    detail_type, 
    title, 
    content, 
    tenant_code
) VALUES (
    'SMS_VERIFY_CODE',
    'mobile',
    'verify_code',
    '验证码',
```

#### 模板参数说明

- `{paramName}`：占位符，会被 `params` 中的值替换
- 参数顺序必须与 `params` 中的顺序一致

## 四、各种消息类型使用示例

### 4.1 站内消息（Site）

**特点：**
- 存储在数据库中
- 用户在系统消息中心查看
- 支持未读/已读状态

```java
@Autowired
private IReminderComposeService reminderComposeService;

public void sendSiteMessage(Long userId, String orderNo) {
    ReminderDTO reminder = new ReminderDTO();
    
    // 必填字段
    reminder.setTemplateType(TemplateType.SITE.getCode());
    reminder.setMessageType(TemplateType.SITE.getCode());
    reminder.setDetailType("order_notify");
    reminder.setTemplateId("TPL_ORDER_001");
    reminder.setReceivers(String.valueOf(userId));
    
    // 消息内容
    reminder.setTitle("订单支付成功");
    Map<String, Object> params = new LinkedHashMap<>();
    params.put("orderNo", orderNo);
    params.put("amount", "999.00");
    reminder.setParams(params);
    
    // 在客户端显示
    reminder.setClientShow(true);
    reminder.setRecord(true);
    
    // 跳转链接
    reminder.setLink("/order/detail/" + orderNo);
    
    // 发送
    reminderComposeService.push(reminder);
}
```

### 4.3 手机短信（Mobile）

**支持服务商：**
- 阿里云短信
- 腾讯云短信
- 移动云短信

**前置条件：**
1. 在短信平台申请模板
2. 配置 AccessKey、Secret
3. 签名审核通过

```java
public void sendSmsCode(String mobile) {
    ReminderDTO reminder = new ReminderDTO();
    
    // 必填字段
    reminder.setTemplateType(TemplateType.MOBILE.getCode());
    reminder.setMessageType(TemplateType.MOBILE.getCode());
    reminder.setDetailType("verify_code");
    reminder.setTemplateId("SMS_VERIFY_CODE");
    
    // 接收者（手机号）
    reminder.setReceivers(mobile);
    
    // 生成验证码
    String code = RandomUtil.randomNumbers(6);
    Map<String, Object> params = new LinkedHashMap<>();
    params.put("code", code);
    reminder.setParams(params);
    
    // 不记录到站内消息
    reminder.setRecord(false);
    
    reminderComposeService.push(reminder);
    
    // 将验证码存入 Redis，5分钟过期
    redisTemplate.opsForValue().set(
        "sms:code:" + mobile, 
        code, 
        5, 
        TimeUnit.MINUTES
    );
}
```

## 五、高级用法

### 5.1 批量发送消息

```java
public void sendBatchMessages(List<Long> userIds, String message) {
    // 方式1：循环发送（适合少量用户）
    for (Long userId : userIds) {
        ReminderDTO reminder = new ReminderDTO();
        reminder.setTemplateType("site");
        reminder.setMessageType("site");
        reminder.setDetailType("batch_notify");
        reminder.setTemplateId("TPL_BATCH");
        reminder.setReceivers(String.valueOf(userId));
        
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("message", message);
        reminder.setParams(params);
        
        reminderComposeService.push(reminder);
    }
    
    // 方式2：一次性发送给多个用户（推荐）
    ReminderDTO reminder = new ReminderDTO();
    reminder.setTemplateType("site");
    reminder.setMessageType("site");
    reminder.setDetailType("batch_notify");
    reminder.setTemplateId("TPL_BATCH");
    
    // 多个用户ID用逗号分隔
    String receivers = userIds.stream()
        .map(String::valueOf)
        .collect(Collectors.joining(","));
    reminder.setReceivers(receivers);
    
    Map<String, Object> params = new LinkedHashMap<>();
    params.put("message", message);
    reminder.setParams(params);
    
    reminderComposeService.push(reminder);
}
```

### 5.3 定时发送消息

结合 Quartz 或 Spring Schedule：

```java
@Component
public class ScheduledMessageTask {
    
    @Autowired
    private IReminderComposeService reminderComposeService;
    
    // 每天早上9点发送提醒
    @Scheduled(cron = "0 0 9 * * ?")
    public void sendDailyReminder() {
        List<UserDTO> users = userService.getAllUsers();
        
        for (UserDTO user : users) {
            ReminderDTO reminder = new ReminderDTO();
            reminder.setTemplateType("site");
            reminder.setMessageType("site");
            reminder.setDetailType("daily_reminder");
            reminder.setTemplateId("TPL_DAILY");
            reminder.setReceivers(String.valueOf(user.getId()));
            
            Map<String, Object> params = new LinkedHashMap<>();
            params.put("date", LocalDate.now().toString());
            reminder.setParams(params);
            
            reminderComposeService.push(reminder);
        }
    }
}
```

### 5.4 多租户环境下的消息发送

```java
public void sendMessageInTenant(String tenantCode, Long userId, String message) {
    // 方式1：手动设置租户上下文
    TenantDTO tenant = tenantService.getByCode(tenantCode);
    LocalTenantContext.set(tenant);
    
    try {
        ReminderDTO reminder = new ReminderDTO();
        reminder.setTemplateType("site");
        reminder.setMessageType("site");
        reminder.setDetailType("tenant_notify");
        reminder.setTemplateId("TPL_TENANT");
        reminder.setReceivers(String.valueOf(userId));
        reminder.setTenantCode(tenantCode);  // 显式设置
        
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("message", message);
        reminder.setParams(params);
        
        reminderComposeService.push(reminder);
    } finally {
        LocalTenantContext.clear();
    }
    
    // 方式2：让框架自动从上下文获取（推荐）
    // 只要在当前请求的租户上下文中，无需手动设置
}
```

### 5.5 工作流中的消息通知

框架已内置工作流消息通知，参考 `WorkflowNotifyServiceImpl`：

```java
// 工作流节点触发时自动发送
@Override
public void notify(NotifyConfig notifyConfig) {
    List<NotifyDetail> activeDetails = notifyConfig.getActiveDetails();
    
    for (NotifyDetail detail : activeDetails) {
        ReminderDTO reminder = new ReminderDTO();
        
        if ("wechat".equals(detail.getCode())) {
            reminder.setTemplateType(TemplateType.WECHAT.getCode());
            reminder.setReceivers(userExternalId);
        } else if ("mobile".equals(detail.getCode())) {
            reminder.setTemplateType(TemplateType.MOBILE.getCode());
            reminder.setReceivers(userMobile);
        } else if ("email".equals(detail.getCode())) {
            reminder.setTemplateType(TemplateType.EMAIL.getCode());
            reminder.setReceivers(userEmail);
        }
        
        reminder.setTemplateId(detail.getTemplateId());
        reminderComposeService.push(reminder);
    }
}
```

## 八、最佳实践

### 8.1 消息发送原则

1. **重要消息多渠道发送**
   ```java
   // 同时发送站内消息和短信
   sendSiteMessage(userId, message);
   sendSmsMessage(mobile, message);
   ```

2. **避免频繁发送**
   ```java
   // 使用 Redis 做频率限制
   String key = "msg:limit:" + userId + ":" + messageType;
   if (redisTemplate.hasKey(key)) {
       throw new BusinessException("发送过于频繁，请稍后再试");
   }
   redisTemplate.opsForValue().set(key, "1", 1, TimeUnit.MINUTES);
   ```

3. **敏感信息脱敏**
   ```java
   // 不要直接在消息中展示完整手机号、身份证等
   String maskedPhone = phone.replaceAll("(\\d{3})\\d{4}(\\d{4})", "$1****$2");
   ```

4. **记录关键消息**
   ```java
   reminder.setRecord(true);  // 保存到数据库，便于追溯
   ```

### 8.2 性能优化

1. **批量发送使用逗号分隔**
   ```java
   // ✅ 推荐：一次调用
   reminder.setReceivers("1001,1002,1003");
   
   // ❌ 不推荐：循环调用
   for (String userId : userIds) {
       reminder.setReceivers(userId);
       push(reminder);
   }
   ```

2. **异步发送非关键消息**
   ```java
   @Async
   public void sendNotification(ReminderDTO reminder) {
       reminderComposeService.push(reminder);
   }
   ```

3. **关闭不必要的消息记录**
   ```java
   // 验证码等临时消息不需要记录
   reminder.setRecord(false);
   ```

### 8.3 错误处理

```java
try {
    Response response = reminderComposeService.push(reminder);
    if (!response.success()) {
        log.error("消息发送失败：{}", response.getMessage());
        // 重试或记录日志
    }
} catch (Exception e) {
    log.error("消息发送异常", e);
    // 异常处理
}
```

## 九、常见问题

### Q1: 消息发送失败，提示"未找到模板"？

**原因：** 消息模板未配置或配置错误

**解决：**
1. 检查数据库中是否有对应的模板记录
2. 确认 `templateType`、`detailType`、`templateId` 与数据库一致
3. 确认租户编码正确

### Q2: 企业微信消息收不到？

**原因：** 配置错误或用户未关注

**解决：**
1. 检查企业微信应用配置（CorpId、AgentId、Secret）
2. 确认用户的 `externalId` 正确
3. 确认用户已关注企业微信应用
4. 查看企业微信管理后台的应用日志

### Q3: 短信发送失败？

**原因：** 余额不足、模板未审核、签名错误

**解决：**
1. 检查短信平台账户余额
2. 确认模板已审核通过
3. 确认签名与模板匹配
4. 查看短信平台返回的错误信息

### Q4: 如何自定义消息处理器？

**步骤：**

1. 继承 `AbstractMessageReminder`
2. 实现 `onReminder` 方法
3. 添加 `@Component` 注解

```java
@Component("custom")
public class CustomMessageReminder extends AbstractMessageReminder {
    
    @Override
    protected void onReminder(ReminderDTO reminderDTO, MessageTemplateDTO template) {
        // 自定义发送逻辑
        String content = handlerTemplate(reminderDTO, template);
        
        // 调用第三方 API
        // ...
        
        log.info("自定义消息发送成功");
    }
}
```

### Q5: 微服务和单体模式有什么区别？

**单体模式：**
- 直接调用本地服务
- 配置：`fastsun.platform.type=single`

**微服务模式：**
- 通过 Feign 调用远程服务
- 配置：`fastsun.platform.type=distributed`
- 需要确保 reminder 服务已启动

## 十、完整示例：订单通知系统

### 10.1 场景描述

用户下单后，需要：
1. 发送站内消息
2. 发送短信通知
3. 企业微信通知客服

### 10.2 实现代码

```java
@Service
@Slf4j
public class OrderNotificationService {
    
    @Autowired
    private IReminderComposeService reminderComposeService;
    
    @Autowired
    private UserService userService;
    
    /**
     * 订单创建通知
     */
    public void notifyOrderCreated(OrderDTO order) {
        UserDTO user = userService.findById(order.getUserId());
        
        // 1. 发送站内消息
        sendSiteMessage(user, order);
        
        // 2. 发送短信
        if (StringUtils.hasText(user.getMobile())) {
            sendSmsMessage(user.getMobile(), order);
        }
        
        // 3. 企业微信通知客服
        notifyCustomerService(order);
    }
    
    private void sendSiteMessage(UserDTO user, OrderDTO order) {
        ReminderDTO reminder = new ReminderDTO();
        reminder.setTemplateType(TemplateType.SITE.getCode());
        reminder.setMessageType(TemplateType.SITE.getCode());
        reminder.setDetailType("order_created");
        reminder.setTemplateId("TPL_ORDER_CREATED");
        reminder.setReceivers(String.valueOf(user.getId()));
        
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("orderNo", order.getOrderNo());
        params.put("amount", order.getAmount());
        params.put("createTime", LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss")));
        reminder.setParams(params);
        
        reminder.setTitle("订单创建成功");
        reminder.setLink("/order/detail/" + order.getId());
        reminder.setClientShow(true);
        reminder.setRecord(true);
        
        reminderComposeService.push(reminder);
        log.info("站内消息发送成功：{}", order.getOrderNo());
    }
    
    private void sendSmsMessage(String mobile, OrderDTO order) {
        ReminderDTO reminder = new ReminderDTO();
        reminder.setTemplateType(TemplateType.MOBILE.getCode());
        reminder.setMessageType(TemplateType.MOBILE.getCode());
        reminder.setDetailType("order_created");
        reminder.setTemplateId("SMS_ORDER_CREATED");
        reminder.setReceivers(mobile);
        
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("orderNo", order.getOrderNo());
        params.put("amount", order.getAmount());
        reminder.setParams(params);
        
        reminder.setRecord(false);  // 短信不记录到站内
        
        reminderComposeService.push(reminder);
        log.info("短信发送成功：{}", mobile);
    }
    
    private void notifyCustomerService(OrderDTO order) {
        // 获取客服企业微信ID
        List<String> customerServiceIds = getCustomerServiceWechatIds();
        
        if (customerServiceIds.isEmpty()) {
            return;
        }
        
        ReminderDTO reminder = new ReminderDTO();
        reminder.setTemplateType(TemplateType.WCP.getCode());
        reminder.setMessageType(TemplateType.WCP.getCode());
        reminder.setDetailType("new_order");
        reminder.setTemplateId("TPL_WCP_NEW_ORDER");
        reminder.setReceivers(String.join(",", customerServiceIds));
        reminder.setReceType("touser");
        reminder.setWechatType("textcard");
        
        Map<String, Object> params = new LinkedHashMap<>();
        params.put("title", "新订单通知");
        params.put("description", String.format("订单%s，金额%s元", order.getOrderNo(), order.getAmount()));
        params.put("url", "http://admin.xxx.com/order/" + order.getId());
        reminder.setParams(params);
        
        reminder.setTitle("新订单");
        reminder.setRecord(true);
        
        reminderComposeService.push(reminder);
        log.info("企业微信通知发送成功");
    }
    
    private List<String> getCustomerServiceWechatIds() {
        // 从配置或数据库获取客服的企业微信ID
        return Arrays.asList("kefu1", "kefu2");
    }
}
```
