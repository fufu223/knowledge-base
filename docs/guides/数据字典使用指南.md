# 数据字典使用指南

## 概述

数据字典（Dictionary）是 Fastsun 平台提供的一项基础数据标准化功能，位于 `fastsun-ucenter` 用户中心模块下（子模块 `fastsun-ucenter-dictionay`）。它用于管理系统中的枚举值和固定选项数据，如性别、状态、类型等，实现业务数据的统一管理和前端联动。

---

## 功能特性

- **字典类型定义**：按业务分类管理字典（如 `gender`、`status`、`notice_type`）
- **字典项管理**：每个类型下可定义多个键值对（code → name）
- **租户隔离**：字典数据按租户隔离，不同租户可维护各自的字典
- **缓存加速**：字典数据缓存到 Redis，提升查询性能
- **前端联动**：前端可直接通过 API 获取字典项，用于下拉框等组件

---

## 管理端操作

### 1. 字典类型管理

通过用户中心管理界面的"字典管理"功能，可以：

- **新增字典类型**：定义字典编码（如 `gender`）和名称（如"性别"）
- **编辑字典类型**：修改名称、说明、排序
- **删除字典类型**：删除整个字典类型及其所有字典项

### 2. 字典项管理

在每个字典类型下维护具体的字典项：

| 字段 | 说明 | 示例 |
|------|------|------|
| 字典编码 | 字典项的唯一标识 | `M` |
| 字典名称 | 字典项的显示名称 | 男 |
| 排序号 | 控制字典项的排列顺序 | 1 |
| 状态 | 启用/停用 | 启用 |
| 扩展属性 | JSON 格式的额外属性 | `{"color":"blue"}` |

## 后端 API

### 查询字典

```java
@Autowired
private IDictionaryService dictionaryService;

// 根据字典类型查询所有字典项
List<DictionaryDTO> dicts = dictionaryService.findByType("gender");

// 结果示例：
// [{code: "M", name: "男", sort: 1},
//  {code: "F", name: "女", sort: 2}]
```

### 查询字典（带缓存）

```java
// 优先从缓存读取，缓存未命中则查数据库
List<DictionaryDTO> dicts = dictionaryService.findByTypeWithCache("order_status");
```

### 获取单个字典项

```java
// 根据字典类型和编码获取具体字典项
DictionaryDTO item = dictionaryService.getItem("gender", "M");
// {code: "M", name: "男"}
```

### 校验字典值

```java
// 判断某个值是否属于指定字典类型
boolean valid = dictionaryService.isValidValue("gender", "M");
// true
```

## 前端使用

### 获取字典列表

```javascript
// GET /api/dict/type/{dictType}
// 响应示例
{
  "code": 200,
  "data": [
    {"code": "M", "name": "男", "sort": 1},
    {"code": "F", "name": "女", "sort": 2}
  ]
}
```

### 下拉框使用示例

```html
<select name="gender">
  <option value="">请选择性别</option>
  <option th:each="dict : ${dictionaries}"
          th:value="${dict.code}"
          th:text="${dict.name}"></option>
</select>
```

### Vue/React 前端

```javascript
// 获取字典列表渲染下拉框
async function loadDict(dictType) {
  const res = await axios.get(`/api/dict/type/${dictType}`);
  this.options = res.data.data;
}
```

## 配置项

```yaml
fastsun:
  platform:
    # 字典缓存配置
    dict:
      cache:
        enabled: true          # 是否启用字典缓存，默认 true
        expire-seconds: 3600   # 缓存过期时间（秒），默认 3600
```

## 最佳实践

### 1. 字典命名规范

- 字典类型编码使用小写蛇形命名：`order_status`、`notice_type`
- 字典项编码统一使用大写字母或数字：`PENDING`、`APPROVED`、`REJECTED`

### 2. 缓存策略

- 字典数据变更不频繁，建议开启缓存
- 字典变更后可通过管理端手动刷新缓存
- 调用 `dictionaryService.evictCache(dictType)` 清除指定类型缓存

### 3. 与枚举配合

对于代码中需要引用的固定字典值，建议配合 Java 枚举使用：

```java
public enum Gender {
    M("男"),
    F("女");

    private String name;

    Gender(String name) {
        this.name = name;
    }
}
```

## 常见问题

### Q1: 字典数据修改后前端没有更新？

A: 字典数据有缓存，修改后需要：
1. 在管理端点击"刷新缓存"
2. 或等待缓存过期自动刷新
3. 或调用 `dictionaryService.evictCache(dictType)` 主动清除

### Q2: 如何导入导出字典数据？

A: 字典数据可以通过 Excel 导入导出：
1. 在字典管理页面导出为 Excel 模板
2. 按模板格式填写字典项
3. 导入到指定字典类型
