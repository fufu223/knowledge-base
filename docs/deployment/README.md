# 🚀 知识库部署说明

## 📖 面向框架使用者

本文档说明如何查看 Fastsun 框架的在线文档。

---

## 💻 本地查看文档

### 方法 1：浏览器直接打开（最简单）

1. 找到 `knowledge-base/index.html` 文件
2. 双击用浏览器打开
3. 即可浏览所有文档

**优点**：无需任何配置，即开即用

---

### 方法 2：使用本地服务器（推荐）

如果有 Node.js 环境：

```bash
cd knowledge-base/tools
.\preview-nodejs.bat
```

访问：`http://127.0.0.1:8080`

**优点**：支持搜索功能，体验更好

---

## 🌐 在线文档

如果团队已部署在线文档，直接访问提供的 URL 即可。

**常见部署平台**：
- GitHub Pages
- Vercel
- 内部文档服务器

请联系团队获取在线文档地址。

---

## ❓ 常见问题

### Q: 文档链接点击后 404？

**A**: 请使用本地服务器方式查看（方法 2），不要直接双击 HTML 文件。

### Q: 搜索功能不工作？

**A**: 直接打开 HTML 文件时搜索功能不可用，请使用本地服务器方式。

### Q: 如何获取最新文档？

**A**: 从 Git 仓库拉取最新代码：
```bash
git pull
```

**注意**：本文档仅说明如何查看文档，文档维护相关操作请参考框架开发指南。
